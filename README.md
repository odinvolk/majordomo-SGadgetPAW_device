# majordomo-SGadgetPAW_device
В версии 2 для трансляции в IoTmanager, MQTT, Telegram, RegisterEvent
 
 нужно через простые устройства создать необходимые группы
 
 Название (*): Транслировать в IoTmanager
 Системное имя: IoTmanager
 Получем группу: groupIoTmanager
 
 Название (*): Транслировать в MQTT	
 Системное имя: MQTT
 Получем группу: groupMQTT
 
 Название (*): Транслировать в Telegram
 Системное имя: Telegram
 Получем группу: groupTelegram
 
 Название (*): Транслировать в События
 Системное имя: RegisterEvent
 Получем группу: groupRegisterEvent
 
выбрать устройства в группе 

дальше в новом устройстве выбрать группу для трансляции
если галочка есть то трансляция включена если нет то выключена
